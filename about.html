How it stays honest

Useful information. Not sales pressure.

sources

Official sources only

Every claim links to the official pricing page or documentation. Nothing is invented — if a number is unknown, the entry says to check the page.

freshness

Verified dates on everything

Each entry carries the date it was last checked. Free tiers change constantly — the date tells you how fresh the map is, and a "verify" badge flags volatile ones.

openness

Plain JSON, publicly auditable

All data lives in versioned JSON files in the repository. Anyone can read, fork, correct or extend it — a pull request fixes a stale entry for everyone.

privacy

No tracking, no accounts

No analytics cookies, no sign-in, no data collected. Your region and guide progress live in your browser's local storage and nowhere else.

Frequently asked

Questions people actually ask.

Why does this exist?

Because "what can I use for free?" is the most expensive question on the internet — answered everywhere by SEO landfill and affiliate funnels. One honest, structured, open dataset beats a hundred listicles.

How do you make money?

It doesn't. No affiliate links, no sponsored entries, no ads. Costs are a domain and a free static host. If that ever changes, it will be stated here first.

Can I trust the numbers?

Treat it as a map, not gospel. Entries carry check dates and official links; "verify" badges mark volatile limits. The structure makes checking fast — that's the point.

How can I help?

Star the repo, fix an entry, add a missing tool, improve a guide, or translate region notes. Everything is one small JSON edit — see the contributing guide.

Is a tool missing or wrong?

Open an issue via the Ask page — suggestions and corrections land in the same inbox and get folded into the data.

What's the tech stack?

Deliberately boring: plain HTML/CSS/JS, zero dependencies, no build step, static JSON data. It should outlive every framework and stay forkable forever.
